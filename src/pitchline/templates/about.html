{{ SITE_NAME }} is a soccer data project built end to end by {{ OWNER }}, a data engineer completing an M.S. in Data Science at UC San Diego. It tracks who shoots and who finishes across nine competitions, shows where shots come from, forecasts shots on target, and keeps a public scorecard of how those forecasts turn out.

What is under it

  • A scheduled pipeline (Python, GitHub Actions) downloads match data, parses the commentary into one row per shot, checks every match against the source's own totals, and stores one JSON file per match in Amazon S3.
  • This site is rebuilt from those files automatically, so a finished match appears without manual work.
  • Forecasts use a Poisson model trained on past matches and are judged against a simple baseline in a time-ordered backtest; the results are on the forecast page, including when the model is no better than the baseline.
  • Everything is open source and tested; see how it is built and the method and data quality.
