Walk-forward backtest

Not one split but {{ card.n_folds }} successive test periods ({{ card.test_from }} to {{ card.test_to }}). Each period is predicted by a model trained only on matches before it, so every prediction is on matches the model never saw. Lower is better. The model must beat the baseline in most periods and its gain must stay positive when whole matches are resampled (paired bootstrap). {% if card.beats_baseline %}It did: the {{ best_name }} won {{ card.wins }} of {{ card.n_folds }} periods, with an average gain of {{ fmt(card.gain.mean, 3) }} deviance per player-match (95% interval {{ fmt(card.gain.lo, 3) }} to {{ fmt(card.gain.hi, 3) }}), so it is used.{% else %}It did not: the best model won {{ card.wins }} of {{ card.n_folds }} periods and its gain was {{ fmt(card.gain.mean, 3) }} (95% interval {{ fmt(card.gain.lo, 3) }} to {{ fmt(card.gain.hi, 3) }}), so the baseline is used. That is a real result: shots on target are noisy and a simple rule is hard to beat.{% endif %}

How much do outcomes spread around the forecast?

Shots on target vary more from match to match than a Poisson allows: a player has good and bad days beyond what his average says. The forecast therefore uses a negative binomial with a dispersion of {{ "%.2f"|format(card.alpha) }}, measured on the test periods above{% if card.likelihood %}. On those matches it gave the actual outcomes an average log-likelihood of {{ fmt(card.likelihood.negative_binomial, 3) }}, against {{ fmt(card.likelihood.poisson, 3) }} for a plain Poisson (higher is better){% endif %}.

Method: for each player in each match, features known before kickoff (own shots-on-target rate over recent matches, shrunk toward the average, expected minutes, how often he starts, days since his last match, home or away, the team's shot volume and the opponent's shots conceded) feed Poisson-loss models: a regression, scikit-learn boosting and LightGBM. Newer matches are always the test set, and nothing is hidden when the model does not win. The full description, with limits, is in the model card.
