Where the numbers come from

Match data comes from ESPN's public match-summary endpoints, which are unofficial and can change without notice. Shots on target, goals and assists are ESPN's own per-player match statistics, added up across the stored matches. Players are identified by ESPN athlete id, so two players with the same name stay separate. Per-90 rates use only matches where the player's minutes are known, and only for players with at least {{ min_per90 }} minutes.

How it is checked

For every match, the shots parsed from the commentary are compared with ESPN's team totals. A match counts as reconciled when they agree exactly. Where ESPN's team totals are empty (some older seasons), the parsed shots are compared with the sum of ESPN's player statistics instead. Matches that do not reconcile are flagged and retried, never hidden.

Expected goals (xG)

xG is the chance that a shot becomes a goal, estimated from where and how it was taken: distance and angle to goal, header or foot, and open play, penalty, free kick or corner. The outcome is never an input. It uses only shots with a usable location, and the xG shown for each shot comes from a model that never saw that match.

Known limits

  • ESPN counts some blocked shots as on target. This site uses ESPN's own on-target numbers, so some players differ from other data providers.
  • A small number of matches have incomplete commentary at the source and stay flagged.
  • Totals cover only the stored matches and date ranges above, not a full history.
  • Minutes and appearances exist only for matches stored with a lineup; players without one show "-".
  • Shot locations come in two ESPN formats (0-100 with the goal at 100, and 0-1 with the goal at 0). The shot maps detect the format for each match. Some shots have no location and are not drawn.
  • The "Best of the best" page adds a player's matches across competitions without adjusting for league strength, so treat it as a count, not a verdict on quality.
  • xG is an estimate from shot location, body part and situation only, validated against ESPN's own goals as described above, not against another provider's xG.

How it is built

A scheduled GitHub Actions job downloads new matches, parses them, checks them and writes one JSON file per match to Amazon S3. Another job rebuilds this site from those files and publishes it. Code, tests and design notes are in the GitHub repository.
